Input triage: does this file need OCR?

From Lesson 1. Facts checked 12 Sep 2026.

OCR is for pixels. DOCX files and born-digital PDFs already contain characters. What breaks them is order and encoding, not recognition.

Three containers

FileWhere the words areHow to read itOCR?Watch for
DOCXCharacters in XML: <w:p> › <w:r> › <w:t> in word/document.xmlUnzip, parse the XMLOnly embedded images with textHeaders and footers in their own parts; text boxes as separate stories
Born-digital PDFGlyphs drawn at positions, plus a glyph-to-Unicode mapExtract the text layer, then rebuild reading orderNoColumns and sidebars; a garbled map, shown as (cid:x) or gibberish on copy-paste
Image-only PDFOne picture per page, zero charactersNothing to extractYes, every pageScans carrying an earlier tool's OCR layer; "flattened" files that kept their text

Four questions, in order

  1. Is it a DOCX? Read the XML: body, headers, footers, text boxes. OCR only embedded images that contain text.
  2. PDF: does the page have a text layer? If not, OCR the page.
  3. Does it copy-paste as real words? If not, treat it as a picture and OCR it.
  4. Is it in reading order? Columns or sidebars need layout analysis (ladder rung 2). Still no OCR.

Checks by hand

  • DOCX: copy the file, rename the copy to .zip, open word/document.xml (Microsoft Learn).
  • Encoding: paste a line from a PDF viewer into a text editor. Gibberish there means gibberish for any extractor (pdfminer.six FAQ).
  • Order, roughly: paste a whole page. Sidebar lines mixed into job bullets mean a layout problem.
  • Beware Live Text: Preview on a Mac can select words inside pictures by recognising them on the fly (Apple Support). Selectable text doesn't prove a text layer.
  • Reliable: the file inspector in Lesson 1 counts characters and images on each page.

Ask any vendor

  • Do you read the text layer when one exists, or OCR every page?
  • What do you do with DOCX: parse the XML, or render it to images?
  • How do you detect columns and rebuild reading order?
  • Can you show accuracy split by file type, including image-only PDFs?
